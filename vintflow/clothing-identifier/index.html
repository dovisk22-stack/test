Identify the item, not just the brand

A brand can make hundreds of different garments. Start with the item type: for example, a crew-neck sweatshirt versus a zip hoodie. Then check the logo, any label, distinctive pattern and product code. Search the exact combination instead of the brand by itself.

What VintFlow AI can help recognise

Upload a whole-item photo and a readable label. The scanner suggests visible brand, size, colour and garment category where it can. Unclear details should be left unconfirmed. Correct the draft if the label, size or item type was misread.

Make a better search from the result

Try the specific garment type and brand plus a distinctive feature. If the label shows a model or style code, search it separately. Record what you actually know and avoid unsupported claims about designer authenticity or vintage age.

Next steps

After checking the identity, use the value checker to compare prices or the description generator to make an honest listing. For older garments, the Vintage Fashion Guild Label Resource offers useful reference material.

VintFlow AI offers editable suggestions, not certified valuations or guaranteed sales. Always review your item and publish it yourself.
